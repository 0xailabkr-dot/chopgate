## Disclosures

`./check.sh` uses an offline mock judge. The files in `fixtures/jev_live/` are fixed test inputs; the `recorded_q1_scene*.json` and `recorded_q2_scene*.json` files are recorded live JEV answers that the tests replay offline. Source classification and caller-declared context are not instruction source proofs. The UI is sample data and mock signing of inner payloads, not a v3 signing client. `./check.sh` prints `CHECK: elapsed <n>s`; it has no time limit. The v3 signature format and state layout are incompatible with existing state without migration.
